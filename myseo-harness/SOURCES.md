# SOURCES

## Jerarquía de fuentes

1. Contratos, aprobaciones formales y fuentes operativas autorizadas.
2. Exportes reproducibles, bases auditadas y documentación oficial.
3. Entrevistas y actas validadas.
4. Informes internos y análisis derivados.
5. Investigación externa vigente y citada.
6. Memoria del LLM o conocimiento no verificado.

Registrar para cada fuente: ubicación, propietario, fecha de corte, autoridad, uso permitido y restricciones de privacidad.
