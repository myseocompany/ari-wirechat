# MySEO Harness local

Marco operativo local para tareas de crecimiento, análisis comercial y Revenue Architecture dentro de ARI WireChat.

Se deriva del arnés de MySEO, pero contiene únicamente reglas y formatos reutilizables. No incluye memoria, tareas, decisiones, resultados ni datos de otros clientes. Los registros específicos de este repositorio están en la raíz: `TASKS.md`, `DECISIONS.md`, `MEMORY.md` y `SOURCES.md`.

Para integrar cambios del arnés de origen, comparar primero y adoptar solo los que sean compatibles con las restricciones de privacidad y producto de este repositorio.
